# WEB GURU AI V1

Aplikasi web sederhana untuk administrasi guru.

## Fitur V1
- Dashboard
- Data Siswa
- Absensi
- Penilaian
- AI Guru (generator template lokal)
- Responsive untuk laptop dan HP
- Penyimpanan data sementara menggunakan localStorage browser
- Siap dipublikasikan dengan GitHub Pages

## Cara menjalankan
Buka `index.html` di browser.

## Cara deploy ke GitHub Pages
1. Buat repository GitHub, misalnya `web-guru-ai`.
2. Upload `index.html`, `style.css`, `script.js`, dan `README.md`.
3. Buka **Settings → Pages**.
4. Pilih **Deploy from a branch**.
5. Branch: `main`, folder: `/ (root)`.
6. Klik **Save**.
7. Tunggu proses deployment dan buka alamat GitHub Pages yang diberikan.

## Catatan
V1 menggunakan localStorage sehingga data hanya tersimpan pada browser/perangkat yang digunakan. Untuk penggunaan sekolah secara nyata, V2 dapat dikembangkan dengan login, database online, import/export Excel, dan backend/API.
